# CRONOS · Termux

**الإصدار 3.0.1 — نسخة قيد التحقق — ترخيص MIT**

[English](README.md) · [سجل التغييرات](CHANGELOG.md) · [تفاصيل البنية](ARCHITECTURE.md) · [حالة الأمان](SECURITY.md)

مشروع مفتوح المصدر لتنزيل الفيديو والصوت من YouTube باستخدام Termux على أندرويد، مع واجهة طرفية متحركة، وإدارة للطابور وسجل التنزيلات. يعمل دون روت، ويعتمد على Python وyt-dlp وFFmpeg.

## حالة هذه النسخة

هذا المستودع يحتوي على الشيفرة المصدرية لأحدث نسخة محفوظة من CRONOS. الإصدار 3.0.1 ما زال **قيد التحقق**؛ ملف `requirements.lock` المرفق غير مكتمل عمدًا، ولذلك يمنع المثبّت التثبيت الجديد المقفل وتحديث المحرك المقفل. لا تُعرض هذه النسخة على أنها إصدار مستقر جاهز للتثبيت من الصفر.

يمكن ترقية شيفرة تثبيت 3.0.0 يعمل بالفعل بإعادة استخدام اعتمادياته الحالية. يلزم إكمال ملف الاعتماديات ومراجعته، ثم التحقق على جهاز أندرويد، قبل إصدار نسخة مستقرة. توجد التفاصيل وخطوات الصيانة في [README الإنجليزي](README.md) و[SECURITY.md](SECURITY.md).

## المزايا

- تنزيل الفيديو بدقات تصل إلى 4K عندما يوفرها المصدر، ودمج الصوت والفيديو عبر FFmpeg.
- استخراج الصوت إلى MP3 وM4A وOPUS وFLAC وWAV، مع الوسوم والغلاف حيث تدعمه الصيغة.
- قوائم تشغيل، واختيار عناصر محددة، وحدود لعدد التنزيلات، وتجاوز الملفات المسجلة سابقًا.
- طابور محفوظ في SQLite مع الأولويات والإيقاف والاستئناف وإعادة المحاولة.
- بحث محلي في الملفات، وإحصاءات، وتصدير، ونسخ احتياطي للإعدادات والسجل.
- مقدمة متحركة وإعدادات للمظهر والسرعة وتقليل الحركة.

## الحصول على الشيفرة

داخل Termux:

```bash
pkg install -y git
git clone https://github.com/KRONOSERA/CRONOS-Termux.git
cd CRONOS-Termux
```

استنساخ المستودع ينسخ ملفات المصدر فقط. راجع حالة التثبيت أعلاه قبل تشغيل المثبّت.

## ترقية تثبيت 3.0.0 يعمل بالفعل

أنهِ التنزيلات وأغلق جلسات CRONOS الأخرى أولًا، ثم شغّل من مجلد المستودع:

```bash
bash install.sh
cronos
```

ينشئ المثبّت نسخة احتياطية للإعدادات وقاعدة البيانات قبل تعديل البيئة. تبقى ملفات الوسائط في مساراتها السابقة، وتبقى أسماء المجلدات الداخلية القديمة `cronos-yt` من أجل التوافق. إذا لم يجد المثبّت اعتماديات التثبيت السابق، فسيتوقف حتى يتوفر ملف اعتماديات مقفل صالح.

## أوامر مفيدة بعد التثبيت

```bash
cronos                       # فتح الواجهة الرئيسية
cronos --motion-preview      # معاينة الحركة دون تنزيل
cronos --no-animation        # جلسة دون مؤثرات الحركة
cronos --doctor              # فحص البيئة المحلية
cronos --library             # استعراض الملفات المسجلة
cronos --queue-list          # عرض الطابور
cronos --backup              # نسخة احتياطية للإعدادات والسجل
cronos --version             # عرض الإصدار
```

## متطلبات التشغيل

Android مع Termux وPython 3.12 أو أحدث وFFmpeg وNode.js والاعتماديات المحددة في المشروع. عند استخدام التخزين المشترك، شغّل `termux-setup-storage` وامنح إذن التخزين.

## الاختبارات

بعد توفير الاعتماديات الحقيقية:

```bash
python -m unittest discover -s tests -v
python -m compileall -q cronos_yt
bash -n install.sh
```

الاختبارات المحلية لا تثبت نجاح التنزيل من YouTube أو التوافق مع كل هاتف. راجع مصفوفة التحقق في README الإنجليزي. لاختبار الجهاز توجد أداة `verify_termux.sh`، وللتحقق قبل إصدار مستقر يوجد `scripts/ci_check.sh` الذي يتطلب ملف اعتماديات صالحًا وأدوات التدقيق.
