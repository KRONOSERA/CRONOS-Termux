# CRONOS architecture

`cronos_yt/cli/parser.py` declares CLI flags without side effects; `cli/dispatch.py` handles authorization-aware transfer/queue dispatch and noninteractive flows; `cli/menus.py` owns the interactive Rich/Questionary screens; and `cli/__init__.py` preserves the public entry points and application startup. `authorization.py` stores per-job URL digests and session-bound receipts in the existing SQLite database, while `queue.py` manages durable jobs with boot-aware leases; `downloader.py` enforces receipts before yt-dlp is invoked. `updater.py` handles locked dependency updates and verified wheel-cache rollback; media persistence remains in `history.py` and `storage.py`. Animated UI code stays in `ui.py` and `motion.py`, independent from the transfer engine. SQLite schema migrations are additive, settings are atomically written, and no install or migration moves user media.
